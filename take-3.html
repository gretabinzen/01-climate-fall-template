Temperature Data from Montpelier, VT (1960-2020)¶

In this assignment I analyze temperature data from Montpelier, VT from 1960 to 2020. The code below demonstrates my process for bringing in the data from NOAA, organizing the data to show the information I was looking for, and then plotting the data in a userfriendly manner.

Wrangle the Data This first section of code is to import the data from NOAA. I selected a station based in Montpelier Vermont because it had good continuous data over a long period of time. I choose to import data from 1960 to 2020 and to set the maximum daily temperature as my desired variable.
